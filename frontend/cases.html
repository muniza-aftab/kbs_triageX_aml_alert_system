Worked examples

Each example was written to test one specific thing the system should do. Every one records, in its own file, the decision it is expected to receive, so if the rules change and an example stops behaving, the test suite fails.

Some of these exist to show the system getting a hard case right. Others exist to show it declining, including one where declining is arguably unhelpful and it does so anyway. Those are the interesting ones.
